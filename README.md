# Telegram-бот на Python

## Описание проекта

Проект разработан в рамках практической работы «Создание бота в Telegram (Python)».

Цель работы — разработать Telegram-бота, реализовать взаимодействие с внешними API, добавить обработку исключений и логирование, а также развернуть проект на удалённом сервере и опубликовать исходный код на GitHub.

## Возможности бота

- **/start** — приветствие пользователя и отображение главного меню.
- **/myid** — получение Telegram ID пользователя.
- **Фото котика** — отправка случайной фотографии котика через TheCatAPI.
- **Сгенери аватар** — генерация аватара с помощью RoboHash.
- **Мой ID** — отображение идентификатора пользователя.
- **IP сервера** — определение публичного IP-адреса сервера через ipify.
- **Погода сегодня** — получение текущей погоды по геолокации пользователя через OpenWeatherMap.

## Структура проекта

- `main.py` — точка входа в программу.
- `bot.py` — настройка бота и регистрация обработчиков.
- `handlers.py` — обработка команд, сообщений и геолокации.
- `utils.py` — вспомогательные функции и запросы к внешним API.
- `requirements.txt` — список необходимых библиотек.
- `.gitignore` — исключение конфиденциальных и временных файлов из Git.

## Установка и запуск

1. Скачать проект с GitHub.
2. Создать виртуальное окружение:

   `python -m venv venv`

3. Активировать окружение в Windows:

   `.\venv\Scripts\Activate.ps1`

4. Установить зависимости:

   `pip install -r requirements.txt`

5. Создать файл `.env` и добавить переменные окружения:

   `TOKEN=ваш_токен_telegram`

   `TOKEN_WEATHER=ваш_ключ_openweathermap`

6. Запустить бота:

   `python main.py`

## Обработка ошибок

Для повышения надёжности программы реализована обработка исключений с помощью `try/except` и проверок `if/elif/else`.

Предусмотрена обработка следующих ситуаций:

- Отсутствие или неправильная настройка токенов.
- Ошибки подключения к внешним API.
- Некорректные URL запросов.
- Ошибки HTTP.
- Неполные или некорректные JSON-ответы.
- Ошибки получения геолокации.

При возникновении ошибок бот выводит пользователю соответствующее сообщение.

## Логирование

В проекте используется стандартная библиотека Python `logging`.

Логирование позволяет отслеживать запуск программы, обращения к API, предупреждения и возникающие ошибки.

Настроен уровень логирования `INFO`. Сообщения содержат дату, время, уровень события, название модуля и описание события.

## Развёртывание на сервере

Для размещения Telegram-бота используется облачная платформа PythonAnywhere.

На сервер были загружены файлы проекта, создано виртуальное окружение и установлены необходимые библиотеки.

После настройки переменных окружения бот был запущен через Bash-консоль.

Во время запуска возникла ошибка `409 Conflict`, связанная с одновременной работой двух экземпляров бота. Проблема была решена остановкой локального экземпляра программы.

После устранения конфликта бот был запущен на PythonAnywhere.
